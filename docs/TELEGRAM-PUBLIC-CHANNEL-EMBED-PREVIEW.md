# Telegram public-channel embeds (Preview)

TX.TOP can display posts from public Telegram channels without downloading or copying their media. The Telegram post remains hosted by Telegram and is rendered using Telegram's supported public-post embed URL.

## Preview-only configuration

Set `TELEGRAM_PUBLIC_POSTS_JSON` in the **Preview environment only** for the TX.TOP Preview deployment. Do not configure it in Production.

Example value:

```json
[
  {
    "channel": "your_public_channel",
    "messageId": "123",
    "title": "Video title",
    "description": "Optional description",
    "category": "Video",
    "poster": "https://example.com/poster.jpg",
    "rating": "NR"
  }
]
```

- `channel`: public Telegram channel username, with or without leading `@`.
- `messageId`: numeric post ID from the public post URL, e.g. `https://t.me/channel_name/123`.
- `title`, `description`, `category`, `poster`, `rating`: optional display metadata.
- Up to 100 entries are read. Invalid usernames and message IDs are ignored.
- The embed URL is generated by the server as `https://t.me/<channel>/<messageId>?embed=1`; arbitrary iframe URLs are not accepted through this setting.
- No Telegram bot token, webhook, database, Supabase project, or media storage is required.

## Important limitations

- Only public channel posts can be embedded. Private channels, invite links, and private group messages are not supported.
- The post must remain publicly accessible and Telegram must allow embedding it. Deleted, restricted, or unavailable posts will not play.
- The video is played by Telegram's embedded player; TX.TOP does not download, proxy, transcode, or host the media.
- Public visibility is not a distribution license. Add only content you own or are explicitly authorized to display and distribute. Respect takedown requests and applicable age/content rules.
- Telegram may show its own UI, attribution, and playback restrictions inside the iframe.

## Rollback

Remove or set `TELEGRAM_PUBLIC_POSTS_JSON=[]` in the Preview environment and redeploy the Preview. No Production configuration is changed by this integration.
